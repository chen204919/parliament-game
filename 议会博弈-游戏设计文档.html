《议会博弈》

游戏设计文档 (Game Design Document) · 完整版

博弈论策略 · 多人在线谈判 · 2D 暗黑权谋风 · 更新于 2026-08-26

4-6 名玩家进入一个虚拟议会，每局 5-7 轮，通过谈判结盟、投票、背叛来最大化自己的政治资本。每个机制背后都映射一个经典博弈论模型，把"重复博弈 + 声誉"的张力从单局扩展到跨局长线生涯。

一、核心玩法循环

每局游戏由 5-7 轮"议案"组成，每轮包含四个阶段：

1

议案揭示

系统生成利益分配方案，所有玩家可见

2

谈判阶段

限时 2 分钟，私密/公开承诺

3

投票阶段

同时盲投，过半数通过

4

结算与声誉

分配利益，更新兑现率

关键设计点：承诺不强制执行——你答应了却可以反悔，但会被所有人看见，下一轮没人信你。这就是囚徒困境的背叛张力。

二、博弈论内核映射

游戏机制对应模型张力来源
承诺是否兑现囚徒困境短期背叛收益 vs 长期声誉
多轮连续决策重复博弈以牙还牙策略的演化
议案利益分配合作博弈 / 沙普利值谁该拿多少才"公平"
投票 bloc投票博弈 / 少数派悖论关键玩家的杠杆权力
竞价出价拍卖博弈 / 赢者诅咒出价过高反而吃亏
公共贡献公共品博弈搭便车问题

三、谈判系统（游戏灵魂）

  • 私密通道：1v1 加密聊天，可发"承诺"卡（结构化：我做什么 ↔ 你做什么）
  • 公开声明：所有人可见的承诺，违约则声誉暴跌
  • 承诺不绑定执行：答应了可以反悔，但会被所有人看见 → 下一轮没人信你
  • 声誉看板：实时显示每人历史兑现率，是谈判的筹码也是代价

四、持续性设计：从单局到政治生涯

单局制留不住人。核心解法是把单局博弈升级成长线政治生涯，让博弈论最独特的"声誉"机制跨局延续。

图 2 · 持续性分层：meta 层包裹单局核心

五、单局多样性：三轴组合爆炸

一局游戏要"不重样"，靠的是三个维度的组合爆炸——议题库 × 身份系统 × 局内事件，每局随机抽取组合，让固定策略失效。

图 3 · 三轴组合爆炸：120 种基础配置
设计红线：身份能力只解锁策略多样性，不解锁纯数值优势。阴谋家能窥探私聊是信息优势，但不能直接加政治资本——否则变成 pay-to-win 就失去博弈公平性。

六、视觉风格：暗黑权谋风

纯 CSS 营造权谋感，不靠美术资源。墨色为底、暗金为锋、衬线立威。三根支柱：

  • 墨色为底：墨黑 #0E0E10 主背景，暗炭 #1A1A1E 做卡片表面，层次靠明度差而非边框堆砌。
  • 暗金为锋：暗金 #C9A961 是全屏唯一高饱和色，只用于政治资本数值、身份徽章边框、声誉条填充。警示红专给背叛，信任绿专给已兑现。一色一义，绝不滥用。
  • 衬线立威：标题用衬线体（Georgia + 思源宋体），正文无衬线保可读性，数据等宽体。字体的庄重感是零成本权谋氛围来源。

七、游戏首页设计

八、玩家对战场景设计

一个持续界面 + 顶部状态栏驱动阶段切换，不是四个独立页面。四阶段在这一个界面流转：议案揭示（议案卡放大居中）→ 谈判（左右分栏）→ 投票（中央盲投卡）→ 结算（开票结果 + 资本变化）。下图展示最复杂的谈判阶段。

关键设计决策：
  • 承诺契约卡是结构化的，不是自由聊天——可被系统追踪、可结算兑现率、可标记违约状态。
  • 议员位声誉条颜色即信息：红色 41%（近期背叛，不可信）、绿色 85%（高信誉）、暗金（自己）。一眼驱动谈判决策。
  • 自己的议员位高亮暗金边框，始终知道"我在桌上的哪个位置"。

九、技术架构：三层分离

告别卡片堆叠。渲染层（Phaser 3 Canvas）与 UI 层（Vue DOM）解耦，都只订阅数据层（Socket.IO + Pinia），互不直接通信。议会桌是引擎渲染的游戏场景，不是 DOM 卡片。

MVP 档议员用程序化绘制（几何头像 + 身份色），动效靠 Phaser 补间动画零美术成本能跑能动，不够权谋
v1 档4-6 张议员立绘（PNG 切图）+ Spine 骨骼动画，配暗金描边可控立竿见影
v2 档议会大厅背景插画 + 粒子特效 + 音效较高完整氛围

已确认决策：MVP 从程序化起步跑通玩法，验证留人后再投入立绘，避免美术返工。

十二、已确认决策记录

  1. 博弈方向：博弈论策略 + 谈判，两者都要
  2. 对战形式：在线多人对战
  3. 视觉风格：暗黑权谋风（深色调 + 金/红强调，纸牌屋式沉浸）
  4. 强调色：暗金 #C9A961
  5. 引擎方向：2D 起步，Phaser 3 渲染层 + Vue UI 层 + Socket.IO/Pinia 数据层
  6. 美术起点：MVP 程序化绘制起步，验证后投入立绘
  7. 数据存放：所有项目文件统一存放 D:\博弈
